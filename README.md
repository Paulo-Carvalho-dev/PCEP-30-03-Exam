## 📚 About This Repository

This repository documents my learning journey and practical exercises while preparing for the **PCEP – Certified Entry-Level Python Programmer** certification.

My goal is to strengthen my Python programming fundamentals, improve problem-solving skills, and build a solid foundation for my career as a Back-End Developer.

My studies are based on the Python course available through Cisco Networking Academy.

- Understand Python syntax and programming fundamentals.
- Work with variables, data types, and operators.
- Apply conditional statements and loops.
- Understand and manipulate data collections.
- Create and use functions.
- Handle exceptions and errors.
- Work with modules and packages.
- Develop logical thinking and problem-solving skills.
- Prepare for the PCEP certification exam.
